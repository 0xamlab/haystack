# The GPU probe's dependencies (CPython 3.14, linux x86_64, CUDA 12.8). Every line is an exact
# pin; the Dockerfile installs this file with `uv pip install --index-strategy unsafe-best-match`
# so the `+cu128` torch build resolves from the PyTorch index while everything else comes from
# PyPI. The versions are the ones the runs of 2026-09-22/24 recorded, with the algenta package
# and the web server brought to what the flagship's requirements.lock pins.
#
# torch 2.9.1+cu128 is what makes `kernels` resolve the torch29-cxx11-cu128-x86_64-linux
# variant, the one CUDA build thyn-ai/algenta-llm publishes. huggingface_hub is held at 1.26.1,
# the version kernels 0.17.1 is published against (the flagship's pin). algenta provides
# prepare_model_checkpoint, the byte-exact Qwen3 tokenizer and the engine resolver; its native
# runtime wheel (algenta-runtime-native, CPython 3.14 only, linux x86_64 = the CUDA variant)
# bundles conform_generate_cuda, lane A's engine, and is pinned here on its own so the build
# fails closed on a different wheel. transformers + safetensors + tokenizers are the float32
# reference and lane D. tqdm, pyyaml and requests are gguf-py's dependencies: the pinned
# llama.cpp's convert_hf_to_gguf.py runs at image build to make lane B's F16 GGUF.
#
# sentencepiece and protobuf are the converter's own requirements at that commit
# (requirements/requirements-convert_legacy_llama.txt: sentencepiece>=0.1.98,<0.3.0,
# protobuf>=4.21.0,<5.0.0). Qwen3Model.set_vocab tries `_set_vocab_sentencepiece` first and only a
# FileNotFoundError (no tokenizer.model) falls through to the GPT-2 vocab path, so the module must
# import even though the checkpoint never uses it (run 16 stopped at ModuleNotFoundError).
# sentencepiece 0.2.2 ships cp314 manylinux_2_28 x86_64 wheels (2026-07-12). protobuf backs the
# sentencepiece model proto the other vocab paths read; the converter's own cap (<5.0.0) cannot
# be honoured on CPython 3.14 — protobuf 4.25.8's abi3 upb extension fails to import there
# (`Metaclasses with custom tp_new are not supported`, checked in the image's interpreter on
# 2026-09-24), while 7.36.2 (a cp310-abi3 upb wheel) imports the model proto cleanly.
