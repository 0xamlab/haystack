# Support

## Getting help

- **Documentation**: [docs.algenta.ai](https://docs.algenta.ai) — start with
  [Quickstart](https://docs.algenta.ai/quickstart) and
  [Self-hosting](https://docs.algenta.ai/self-hosting).
- **Bugs and feature requests**: open a
  [GitHub issue](https://github.com/thyn-ai/algenta/issues) in this repository.
- **Security vulnerabilities**: do **not** open a public issue — see
  [SECURITY.md](./SECURITY.md) for private reporting channels and the
  response timeline that already applies today.

## Support tiers and long-term support: not published yet

This project has real, shipping license editions (Community, Pro, Team,
Enterprise — see
[Licensing & editions](https://docs.algenta.ai/licensing)), but a per-edition
support-tier matrix (response-time targets, channels, escalation paths) and a
formal long-term-support window (which releases receive security backports,
and for how long) have not been published. Both need an owner sign-off before
they're real commitments — a support promise is made to every customer who
reads it, and inventing numbers here would be worse than leaving the gap
visible.

See [docs.algenta.ai/trust/support-policy](https://docs.algenta.ai/trust/support-policy)
for the live version of this page, including the specific proposal on the
table and what changes once it's signed off.

Until that page says otherwise, the only standing commitment is
[SECURITY.md](./SECURITY.md)'s: acknowledgement within 3 business days,
initial severity triage within 7, for every reported vulnerability on every
edition.
